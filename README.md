# Task Manager AI

Fullstack-приложение для управления задачами с AI-помощником.

## Стек

- Backend: Python 3.12, FastAPI, SQLAlchemy 2.0 (async), PostgreSQL, Alembic
- Frontend: React, Vite, Tailwind CSS
- AI: OpenAI API
- Инфраструктура: Docker, Docker Compose, GitHub Actions

## Что умеет

- Регистрация и вход (JWT)
- Создание, редактирование, удаление задач
- Фильтры: все / активные / выполненные
- Приоритеты задач (низкий / средний / высокий)
- AI-помощник: разбивает задачу на подзадачи через GPT
- Статистика: всего / активных / выполнено
